# Online Library System (Book Store)

A JavaFX-based desktop application for managing an online library, implementing various Design Patterns.

## How to Download
1. Click on the ZIP file above
2. Download and extract
3. Open in IntelliJ IDEA
4. Configure JavaFX SDK
5. Run `MainApp.java`

## Features
- User authentication (Login/Signup)
- Three roles: Member, Librarian, Admin
- Borrow/Return books with strategies
- Book management (add, update, delete, search)
- User management (Admin only)

## Design Patterns Used
- Singleton, Factory, Facade, Proxy, Decorator, State, Strategy
